# Log My Day

When I tell you what I did today, or anything I've been up to, save it to my inbox and then propose one topic. Do both in one go.

## Save it

My inbox is the `inbox/` folder, one file per day, named `YYYY-MM-DD.md`. Save what I tell you to today's file, and create it if it isn't there yet. If today's file already exists, add to the end of it. If I'm talking about an earlier day, like yesterday, use that day's file instead.

```markdown
# YYYY-MM-DD

- One thing that happened.
- Another thing.
```

* One bullet per thing that happened, so each one can become its own post later.
* Write it in first person, close to how I said it. Keep the details: names, numbers, what someone said, what broke, how I felt. Tidy the wording, but don't trim details or add anything I didn't say.
* If it changes my background or shows a view I keep coming back to, like a new role or a strong opinion, update [profile.md](../context/profile.md) too.

Save what I gave you without asking follow-up questions first. Then add the day's one-line summary to the dashboard, or update it if the day is already there, as in [maintain.md](maintain.md).

## Propose a topic

Tell me in a few words that it's saved, then give me one topic, the strongest one. Follow [Pick topics](topics.md#pick-topics) for how to pitch it, and save it to the idea bank on the dashboard.

It can come from today, from earlier days I haven't used yet, or from today plus an earlier day that goes with it. If today's stuff is too thin for a post, say so in a sentence and pick from earlier days instead. If it builds on an idea that's already waiting, update that idea instead of adding another.

If I want to write it, go to [write.md](write.md).
