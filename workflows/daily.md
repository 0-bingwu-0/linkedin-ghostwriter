# Log My Day

When I tell you what I did today, or anything I've been up to, save it to my inbox and record what's new about me and my work. Do both in one go.

## Save it

My inbox is the `inbox/` folder: one file per day, named `YYYY-MM-DD.md`, and [index.md](../inbox/index.md) listing the days, newest first. Save what I tell you to today's file, and create it if it isn't there yet. If today's file already exists, add to the end of it. If I'm talking about an earlier day, like yesterday, use that day's file instead.

```markdown
# Tuesday, November 3, 2026

- One thing that happened.
- Another thing.
```

* One line per thing that happened.
* Write it in first person, close to how I said it. Keep the details: names, numbers, what someone said, what broke, how I felt. Tidy the wording, but don't trim details or add anything I didn't say.

Save what I gave you without asking follow-up questions first.

Then update [index.md](../inbox/index.md): for a new day, add a line at the top of the list; for a day that's already there, rewrite its sentence to cover what's new.

```markdown
- [Tuesday, November 3, 2026](2026-11-03.md): The whole day in one short sentence.
```

## Record what's new

Then record what's new about me or my work, as in [AGENTS.md](../AGENTS.md#record-what-i-tell-you). The inbox keeps what I said that day; my work notes keep where things stand now.

## Reply

Tell me in a sentence that it's saved, with what you recorded and where. If something in it would make a good post, say so in one more sentence, and add it to my ideas only if I say so.
