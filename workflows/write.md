# Write the LinkedIn Post

## Before writing

* Read [profile.md](../context/profile.md).
* Read related past posts in [linkedin_posts.md](../output/linkedin_posts.md). Learn the word choice, sentence length, openings, and formatting. Check what I've said before so I don't contradict myself, and build on it where you can.
* If one detail only I would know would make the post much stronger, like a number, what someone said, or why I made a call, ask me for it first. Just that one question. If I don't have it, write without it.

## Writing

Write the draft directly. No outline needed unless I ask. Give me one version first, and alternatives only when I ask.

Follow the writing style in [profile.md](../context/profile.md) and the rules in [AGENTS.md](../AGENTS.md#writing-for-me). For LinkedIn:

* Only the first two or three lines show before "more". Open with the moment or the point that makes people want to keep reading, without clickbait.
* One story or one point per post. Keep it as short as the story allows, and under LinkedIn's 3,000-character limit.
* Short paragraphs with a blank line between them. Don't put every sentence on its own line.
* Use a list only when there really are steps or parallel points.
* Skip LinkedIn clichés: "I'm thrilled to announce", "Here's the thing", "Let that sink in", "Agree?", humblebrags, and big life lessons drawn from small moments.
* End where the story ends. Ask readers a question only when I'd really want their answers.
* No hashtags unless my writing style asks for them.
* If the post needs a link, put it in the first comment.

## Saving

Save it at the top of [linkedin_posts.md](../output/linkedin_posts.md) as soon as it's written, without asking:

```markdown
## YYYY-MM-DD · Topic

Post text

**First comment:** Comment text (if any)
```

When editing, save changes in place. When I approve the post, turn it into X by following [repurpose.md](repurpose.md).
