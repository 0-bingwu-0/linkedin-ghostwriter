# I Have an Idea

An idea is something I want to say about my work: a feeling, a view, something that surprised me. It usually comes before the examples.

When I tell you one, in one go:

* Add it to the top of my ideas on the dashboard, as in [maintain.md](maintain.md#format): today's date and the idea close to my words. If it builds on an idea already there, update that one instead.
* Tell me in a sentence whether my work notes have an example for it yet.
* If it isn't clear how I'd tell it, end with one question: how do I plan to write it? For example, which moment I'd start from, or which example I have in mind. Skip it if I already said, or my work notes make it clear.

When I answer, add it to the idea as its `plan`, in a few words. If I want to write it now, go to [write.md](write.md).

If I plan it as a series, mark the idea as one and write the plan into it, like how many posts and what each covers. If some posts are already written for it, set their `series`, as in [maintain.md](maintain.md#format).
