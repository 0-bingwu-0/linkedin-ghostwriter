# Turn It into X

Do this after I approve a LinkedIn post, or when I ask for an X version of a past one.

## Format

Pick the format that fits the content, and tell me which one you picked in a sentence:

| Content | Format |
| --- | --- |
| One point, opinion, or short story | X Post |
| A few connected points or steps | Thread |
| A tutorial, process, comparison, or full analysis | X Article |

If I pick a format, use it. Check the X Premium setting in [profile.md](../context/profile.md): without Premium, keep each post to 280 characters, turn longer content into a Thread, and don't write long posts or Articles.

## Before writing

* Read [profile.md](../context/profile.md) and the approved LinkedIn post.
* Read related past content in [x_posts.md](../output/x_posts.md) and [x_articles/](../output/x_articles/) to learn how I write on X.

## Writing

Keep the point, the facts, and my experiences from the LinkedIn post. Don't add claims or experiences that aren't in it, in my profile, or in what I've told you. Rewrite it for X instead of trimming the LinkedIn text, and follow the rules in [AGENTS.md](../AGENTS.md#writing-for-me).

* **X Post:** Shorter and more relaxed. Put the point in the first line and cut the setup LinkedIn needed. If it needs a link or extra context, put it in a separate reply.
* **Thread:** Number each post. The first one should make sense on its own.
* **X Article:** Give it a title and sections. Add the details, examples, and public facts (with sources) that the LinkedIn post had no room for, but don't pad it. Write the full draft directly. The LinkedIn post already settled the angle, so no outline.

## Saving

Use the same topic name as the LinkedIn post, so the two are easy to match.

| Content | Location and format |
| --- | --- |
| X Post or Thread | Top of [x_posts.md](../output/x_posts.md) |
| X Article | `output/x_articles/YYYY-MM-DD-<slug>.md`, with only the title and body, including any links the body cites |

Post format:

```markdown
## YYYY-MM-DD · Topic

Post text

**Reply:** Reply text (if any)
```

For a Thread, number each post, with a blank line between them:

```markdown
## YYYY-MM-DD · Topic

1/ First post

2/ Second post
```

Save as soon as it's written, without asking. When editing, save changes in place.
