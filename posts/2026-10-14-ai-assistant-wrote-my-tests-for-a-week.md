# I let an AI assistant write my tests for a week

Last week I let an AI assistant write every test for a feature I was building. I wanted to see how much time it would save.

At first, a lot. It wrote more tests than I would have, and they all passed.

Then I broke the feature on purpose, and most of them still passed. They checked that the code did what the code did, not what it was supposed to do.

What worked better: I wrote down the cases that mattered in plain words first, then asked for tests for those. Fewer tests, but they caught the bug.

I'll keep using it. I just don't let it decide what "working" means.
