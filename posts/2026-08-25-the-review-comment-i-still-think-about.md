# The review comment I still think about

A few months into my first job, a senior engineer left one comment on my pull request: "What happens if this list is empty?"

Nothing, it turned out. The page just went blank. No error, no message, nothing for the user to do.

I fixed it in five minutes. What stuck with me was the question. I'd tested what I expected to happen, not what could happen.

I ask it about my own code now, before anyone else has to. Empty, missing, too long, twice in a row. Most of my bugs live there.
