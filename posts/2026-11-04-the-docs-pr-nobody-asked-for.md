# The docs PR nobody asked for

The second example from my first month of open-source PRs: the one with no code in it.

Before I could change anything in a healthcare app's frontend, I had to get it running on my laptop. That took two hours.

So I wrote the steps down as I went, and opened a PR with just those.

I never write setup steps for my own projects, because I'm the only one setting them up. Here, the next person would have lost the same two hours.

It's the least impressive PR I've sent. It might save people the most time.
